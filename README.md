## Project Description
This project demonstrates DOM manipulation and JavaScript event handling. It includes an interactive To-Do List application, DOM practice exercises and five daily challenges.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Features
- Add and delete tasks.
- Mark tasks as completed or active.
- Filter tasks by status.
- Display remaining task count.
- Clear completed tasks.
- Edit tasks using double-click.
- DOM selection and manipulation exercises.
- Five interactive daily challenges.

## How to Run
1. Clone this repository.
2. Open `index.html` in a browser.
3. Alternatively, use VS Code Live Server.

## Lessons Learned
- I learned how to select HTML elements using `getElementById`, `querySelector` and `querySelectorAll`.
- I learned how to traverse the DOM using parent, child and sibling relationships.
- I learned how to create, modify and remove HTML elements dynamically.
- Event delegation allows newly created tasks to work without attaching individual event listeners to every task.
- I learned how to use `preventDefault()` to stop unwanted form submissions.
- I learned why `textContent` is safer than `innerHTML` when displaying user input.
- I learned how to manage application data using arrays of objects and update the page through rendering functions.

## Challenges Faced
One challenge was connecting the JavaScript file correctly to the HTML page. I solved this by checking the script filename and the browser console.

Another challenge was implementing event delegation so that newly added tasks could respond to clicks.
